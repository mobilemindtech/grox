# Internacionalização

Este capítulo cobre as mensagens traduzidas: os arquivos `messages*.properties`, a escolha do locale, a busca das mensagens, o uso em views, controllers e services, e as mensagens padrão do framework.

## Arquivos

As mensagens ficam em `grails-app/i18n/messages*.properties`, em **UTF-8**, com `{0}`, `{1}`... para argumentos (sintaxe do `MessageFormat`):

```properties
# messages.properties
livro.criado=Livro {0} criado
usuario.email.unique=Já existe um usuário com o e-mail {2}
```

```properties
# messages_en.properties
livro.criado=Book {0} created
```

Arquivos com o mesmo nome em vários jars (a app e bibliotecas `org.grox.lib`) são mesclados; o primeiro do classpath, a aplicação, prevalece.

## Locale da requisição

Nesta ordem:

1. `?lang=en` (guardado na sessão);
2. a sessão;
3. o `Accept-Language`;
4. `grox.i18n.defaultLocale` (padrão: o locale da JVM).

```yaml
grox:
  i18n:
    defaultLocale: pt-BR
```

O locale corrente está em `locale` nas views, e o bean `localeResolver` (`SessionLocaleResolver`) dá `resolveLocale(request)`.

## Busca

Para um código, tenta `messages_<idioma>_<PAIS>`, depois `messages_<idioma>`, depois o locale padrão e por fim `messages`. Se nada for encontrado, vale o `default` ou o próprio código.

## Uso

```html
<g:message code="livro.criado" args="${[livro.titulo]}"/>
<g:message code="nao.existe" default="Texto padrão"/>
<g:message error="${erro}"/>                <%-- erro de validação --%>
```

```groovy
flash.message = message(code: 'livro.criado', args: [livro.titulo])     // controller
messageSource.getMessage('livro.criado', [l.titulo] as Object[], null, locale)   // service
```

`messageSource.getMessage(code, args, null, locale)` devolve `null` para mensagem inexistente, como no Spring; o `g:message` devolve o código.

## Mensagens padrão

O framework traz, em inglês e português, as mensagens de validação (`default.blank.message`, `default.not.unique.message`, `typeMismatch`...) e as da segurança (`springSecurity.errors.login.*`). Basta definir a mesma chave na aplicação para trocar o texto. Os códigos de cada constraint estão em [Validação, binding e mensagens](validacao.md).

## Recarga

Em desenvolvimento, alterar um `messages*.properties` faz uma recarga leve da aplicação. Veja [Recarga em desenvolvimento](recarga.md).
